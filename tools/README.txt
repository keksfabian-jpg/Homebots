HomeBots - Homefront multiplayer offline with bots
==================================================

Start: double-click HomeBots.exe.

Requirement: Homefront must be installed (Steam). HomeBots reads the maps, models,
textures and sounds directly from the game installation; they are NOT included in
this folder. Default path:
  C:\Program Files (x86)\Steam\steamapps\common\HOMEFRONT
If the game is installed somewhere else, put its path into gamepath.txt
(one line without # at the start).

Language: the same as the game's language setting in Steam
(Steam > Homefront > Properties > Language).

In this folder:
  HomeBots.exe           the game
  assets\                extra files of HomeBots (nuke models / animations / sounds,
                         loudspeaker announcement)
  gamepath.txt           optional path to the Homefront installation
  logs\                  created on the first start (homebots_latest.log)
  homebots_settings.ini  settings (created on the first start)

Controls: as in the original game (Options > Controls). F1 = debug menu.
